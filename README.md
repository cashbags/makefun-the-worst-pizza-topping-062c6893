One funny line pitching the worst pizza topping we could invent:
driveway gravel, hand-sorted for crunch and legally not food in three
states. Entry for the [make.fun competition](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893)
— a deadpan premium-feature pitch for a topping nobody should eat.

Run it: `python3 main.py [output-dir]` writes `entry.txt` (one line,
103 chars, no trailing newline). See DESIGN.md for why this line won
its 12-candidate tournament.
